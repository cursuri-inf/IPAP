# IPAP: caietele cursului

Caietele Python folosite la cursul și la laboratoarele disciplinei **Învățare Profundă Aplicativă cu Python** (Universitatea Tehnică din Cluj-Napoca, Centrul Universitar Nord din Baia Mare). Titular: conf. univ. dr. Cosmin Sabo.

Materialele cursului, temele și notele sunt în Campus Virtual; aici sunt doar caietele, pe care le deschizi în Google Colab.

## Cum deschizi un caiet

1. Apasă butonul **Open in Colab** din dreptul caietului și intră cu contul tău Google.
2. La prima rulare, Colab te avertizează că documentul nu a fost creat de Google. Caietul vine din acest depozit, deci alege **Run anyway**.
3. Ca să păstrezi ce lucrezi, fă întâi o copie: **File → Save a copy in Drive**. Copia ajunge în Drive-ul tău, în folderul *Colab Notebooks*, și de acolo lucrezi mai departe. Ce modifici în caietul deschis direct de aici nu se salvează.

Caietele de bază rulează și pe CPU. Când un caiet are nevoie de GPU, scrie explicit în prima lui celulă (în Colab: **Runtime → Change runtime type**).
